# SMM Assistant

SMM Assistant - это веб-приложение на Flask, которое помогает автоматизировать создание и публикацию постов в социальных сетях.

## Функционал

*   **Генерация постов:** Автоматическая генерация текстового контента для постов с помощью OpenAI.
*   **Генерация изображений:** Автоматическая генерация изображений для постов с помощью OpenAI (DALL-E).
*   **Публикация в VK:** Автоматическая публикация сгенерированных постов в VK.
*   **История постов:** Просмотр истории сгенерированных и опубликованных постов с возможностью:
    *   Редактирования текста поста.
    *   Перегенерации изображения.
    *   Перепоста в VK.
*   **Статистика VK:** Просмотр статистики по подписчикам в VK.
*   **Современный интерфейс:** Стильный и интерактивный интерфейс с эффектом стекла, неоморфизмом и анимированным фоном.

## Технологии

*   **Backend:** Flask, SQLAlchemy, Flask-Migrate, Flask-Bcrypt, Flask-WTF, WTForms
*   **Frontend:** HTML, CSS, Bootstrap, JavaScript, tsParticles
*   **API:** OpenAI, VK API
*   **База данных:** SQLite
*   **Деплой:** Docker, Gunicorn, Nginx, Gevent

## Установка и запуск

### Локальный запуск

1.  **Клонируйте репозиторий:**
    ```
    git clone https://github.com/ai4bordon/SMM_Assistant.git
    cd SMM_Assistant
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```
    python -m venv env
    source env/bin/activate  # для Linux/macOS
    env\Scripts\activate  # для Windows
    ```

3.  **Установите зависимости:**
    ```
    pip install -r requirements.txt
    ```

4.  **Создайте файл `.env`** и заполните его:
    ```
    SECRET_KEY=your_secret_key
    DATABASE_URL=sqlite:///site.db
    OPENAI_KEY=your_openai_key
    ```

5.  **Инициализируйте базу данных:**
    ```
    flask db init
    flask db migrate -m "Initial migration"
    flask db upgrade
    ```

6.  **Запустите приложение:**
    ```
    python main.py
    ```
    или
    ```
    flask run
    ```

### Запуск через Docker

1.  **Установите Docker и Docker Compose.**

2.  **Создайте файл `.env`** и заполните его:
    ```
    SECRET_KEY=your_production_secret_key
    DATABASE_URL=sqlite:///site.db
    OPENAI_KEY=your_openai_key
    ```

3.  **Запустите приложение:**
    ```
    docker-compose up --build -d
    ```

# Docker-образ

Приложение поставляется с готовым Docker-образом, который включает все необходимые зависимости и настройки для запуска приложения.

### Использование Docker-образа

1. Убедитесь, что у вас установлен Docker.
2. Создайте файл `.env` с необходимыми переменными окружения.
3. Запустите приложение с помощью команды:
   ```
   docker-compose up --build -d
   ```

### Сборка собственного образа

Если вы хотите собрать собственный Docker-образ, вы можете использовать предоставленный Dockerfile:
```
docker build -t smm-assistant .
```

Затем запустите контейнер:
```
docker run -p 8001:8001 --env-file .env smm-assistant
```

## API

### Генератор постов

Генератор постов использует модель `gpt-5-nano` для создания текстового контента. Он принимает тему и тон поста, после чего генерирует соответствующий текст.

### Генератор изображений

Генератор изображений использует модель `dall-e-3` для создания изображений. Он принимает текстовое описание изображения и генерирует соответствующее изображение размером 1024x1024.

## Обработка ошибок

Приложение имеет улучшенную систему обработки ошибок, которая включает:

1. **Логирование:** Все ошибки и исключения записываются в логи с подробной информацией и трассировкой стека.
2. **Обработка исключений OpenAI:** Специальная обработка ошибок API OpenAI, включая:
   - Превышение лимита запросов (RateLimitError)
   - Ошибки аутентификации (AuthenticationError)
   - Ошибки подключения (APIConnectionError)
   - Общие ошибки API (APIError)
3. **Механизм повторных попыток:** Для временных ошибок реализован механизм повторных попыток с экспоненциальной задержкой.
4. **Пользовательские сообщения об ошибках:** Пользователям отображаются понятные сообщения об ошибках вместо технических деталей.
5. **Проверка данных:** Валидация входных данных и проверка существования пользователей и постов.
